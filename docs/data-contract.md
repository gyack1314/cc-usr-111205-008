# 路径平均成本

点下标从0开始。index_band=b定义|i-j|<=b，不按两序列长度自动缩放带宽；入口(0,0)、出口(n-1,m-1)本身也必须有共同支持。任一局部点对的分母是其共同通道权重和，不是固定总通道数。局部成本不因路径重复访问同一i或j而去重。

路径点数包含入口，每个合法单调步形成一个新点。水平步指(i+1,j)，垂直步指(i,j+1)；转换步方向或斜步使上一方向连续数归零，各自最多run_limit。目标sum局部成本/点数，不能用长度惩罚或最小和替代；相同平均目标依次用短路径、完整点对序列字典序决胜。通道标准化由配置锁定，不从配准数据重新计算。

domain只清点通道和缺测，不计算点对成本或配准路径。
