# 路径平均成本

点下标从0开始。index_band=b定义|i-j|<=b，不按两序列长度自动缩放带宽；入口(0,0)、出口(n-1,m-1)本身也必须有共同支持。任一局部点对的分母是其共同通道权重和，不是固定总通道数。局部成本不因路径重复访问同一i或j而去重。

路径点数包含入口，每个合法单调步形成一个新点。水平步指(i+1,j)，垂直步指(i,j+1)；转换步方向或斜步使上一方向连续数归零，各自最多run_limit。目标sum局部成本/点数，不能用长度惩罚或最小和替代；相同平均目标依次用短路径、完整点对序列字典序决胜。通道标准化由配置锁定，不从配准数据重新计算。

domain只清点通道和缺测，不计算点对成本或配准路径。

## 配准模块口径（response_data.costs / dp / register）

### 局部代价与共同支持

- 同名通道用配置里锁定的 `center`、正 `scale` 标准化：`z=(x-center)/scale`，通道权重为正且固定，不从配准数据重新估计。
- 点对 `(i,j)` 只在双方均已观测的通道上计算：`c(i,j)=sum_c w_c(z_rc-z_qc)^2 / sum_c w_c`，分母是该点对的共同通道权重和，不是固定总通道数。
- 缺测（JSON `null`）绝不补零；共同通道数少于 `min_channels` 的点对标记为不可用。入口 `(0,0)`、出口 `(n-1,m-1)` 本身不可用即无可行路径。
- 报告逐点对列出 `effective_channels` 与 `missing_channels`；某通道在整条路径上全部缺测但其余共同通道足够时，仍可有路径，并在 `fully_missing_channels` 与 `coverage_losses` 中列覆盖损失。

### 路径约束与目标

- 步长只允许 `(1,1)`、`(1,0)`、`(0,1)`；`(1,0)` 为水平步、`(0,1)` 为垂直步。
- 水平、垂直各自的连续步数不得超过 `run_limit`；**转换步方向或斜步都使上一方向连续数归零**，各自最多 `run_limit`。
- 所有点对必须满足 `|i-j| <= index_band`，带宽不按序列长度自动缩放。
- 目标是 `min_P sum c / |P|`（全局最小平均代价），不是先最小化总和再除以长度；局部成本不因路径重复访问同一 `i` 或 `j` 去重。
- 同分决胜：平均相同先选较短路径，再按完整 `(i,j)` 点对序列字典序。

### 求解与预算

- `dp.parametric_dp` 在增广代价 `c-lam` 上做受 run_limit 约束的最短路（增广长度 DP）。每个 `(格点, 到达状态)` 只按净增广代价剪枝、并列前缀全保留；比例/长度/字典序决胜只在终点进行，因为前缀的比例或长度不决定拼上同一后缀后的全路径排序。
- `dp.solve` 用 Dinkelbach 分式规划驱动：精确模式（整数资料走 `Fraction`）在有限步精确终止，上下界重合、容差为 0；浮点模式按 `solver.tolerance` 停止，只有当上界-下界 `<= tolerance` 才声明 `optimal_within_tolerance`，并同时报告下界、上界与声明容差。
- `solver.state_budget` 限制累计 DP 状态数。预算在首个完整 DP 评估前耗尽时无候选可报；迭代中途耗尽时保留当前候选路径与已知上下界，状态标 `budget_exhausted`，不伪装成最优。
- `dp.enumerate_paths` 用 DFS 穷举小序列的全部合法路径（精确有理），仅用于核对与测试，不用于生产求解。

### 解释边界

- 水平/垂直步只表示某一序列的既有采样点被重复使用，模块不构造插值后的新观测。
- 配准代价只描述锁定标准化口径下的过程相似性，不据配准好坏判断降雨因果。
- 首末点缺支持、索引带或 run_limit 切断全部合法走法时，报告 `status=infeasible` 并区分具体原因。

### 命令

- `python -m response_data.cli register <file>`：输出完整配准报告（点对路径、逐对有效通道与累计成本、长度、复用次数、逐步步法与伸缩分段、上下界与容差、覆盖损失、错误口径对照）。
- `python -m response_data.cli bruteforce <file>`：穷举全部合法路径并与 Dinkelbach 胜者逐条核对。
- `python -m response_data.demo`：运行穷举核对、错误口径反例、同分决胜、重命名/换单位不变性与缺测覆盖五组演示。
- `register --float` 强制浮点模式；默认整数资料自动走精确有理模式。
